# ESG Disclosure NLP Pipeline

A high-fidelity NLP pipeline for extracting Environmental, Social, and Governance (ESG) disclosures from PDF reports and building a structured Knowledge Graph (KG).

## Features

- **Document Parsing**: Robust PDF text extraction using `pdfplumber`.
- **Entity & Relation Extraction**: Utilizes GLiNER for typed entity recognition and GLiREL for relationship extraction.
- **V2 Graph Architecture**: Strictly typed nodes (Entity, Observation, Target, Event) anchored to identified companies.
- **LLM Insights**: Generates structured facts and professional narrative summaries using a remote LLM server.
- **Caching**: Support for saving and loading intermediate extraction results to accelerate iteration on LLM prompts.

## Installation

Ensure you have a Python 3.10+ environment.

```bash
pip install -r requirements.txt
```

## Usage

### 1. Run Full Pipeline
Extract everything from a PDF and generate the graph and insights:
```bash
python main.py path/to/report.pdf
```

### 2. Fast Iteration (LLM-Only)
If you want to tweak the LLM narrative or inference without re-running the extraction models:

First, run with saving intermediates:
```bash
python main.py path/to/report.pdf --save-intermediates
```

Then, run LLM-only mode:
```bash
python main.py path/to/report.pdf --llm-only
```

### 3. Options
- `--skip-llm`: Skip all LLM-dependent steps (useful for debugging the base extraction).
- `--relation-threshold 0.05`: Adjust the confidence threshold for relationship extraction (default is 0.1).
- `--save-intermediates`: Save extraction results to `output/intermediates.json`.
- `--llm-only`: Load results from `output/intermediates.json` and skip the extraction models.

## Outputs

- `output/graph.graphml`: The full Knowledge Graph in GraphML format.
- `output/insights.md`: Professional narrative summary generated by the LLM.
- `output/nodes.csv` & `output/edges.csv`: Flat files for easy analysis or ingestion.
- `output/observations.csv`: Quantitative metrics extracted from the report.

## Visualization

You can visualize the generated graph using the interactive viewer:
```bash
python graph_viewer.py output/graph.graphml
```
